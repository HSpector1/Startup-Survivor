## Found, not fixed (recommendations)

1. **Full Career consequence table compares one month only.** R15B, R17A/B, R22B and R23A spend in the current month and pay back later, so the "another option projects $X more" line can read as a rebuke for a sound investment. PR #2 does this for the Quick Challenge; the same `ALSO_MONTH_4` idea could add a "through Month 4 at no new action" column to `ConsequenceView` in `src/ui/play.tsx`.
2. **R18 overrun is a fixed-cost variance in the live report.** Audit A8 treats the $756/$456/$256 overrun as a fixed (payroll) spending variance because crew payroll is fixed in this model. The knowledge check teaches the rate/efficiency split on the same numbers. A one-line note in the variance callout ("your crew is a fixed cost, so the overrun lands in fixed-cost variance; the rate and efficiency split is in the Round 18 check") would pre-empt the question.
3. **Factoring fee inside operating income** (A12). Defensible for a teaching game; a stricter presentation puts loss on sale of receivables below operating income with interest. Note it in the glossary entry if the team keeps it.
4. **Option tickets are `<button>` elements containing `<ul>` and `<dl>`.** Browsers and screen readers handle it (the accessible names are complete), but it is invalid HTML. A `<div role="button">` or moving the lists outside the button would make it valid.
